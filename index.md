# T-CAN

Android app that reads live CAN-bus data from a Tesla through a Bluetooth OBD-II adapter
(ELM327-compatible, vLinker, OBDLink) and shows it as dashboards: battery, cells, motors,
temperatures, raw frames.

Everything runs on the phone. No account, no server, no data collection.

## Editions

- **T-CAN** — full version with all dashboards, CAN logger and snapshots.
  [Google Play](https://play.google.com/store/apps/details?id=app.tcan)
- **T-CAN Lite** — free connection check: adapter status, protocol, frame rate and a few live
  parameters. [Google Play](https://play.google.com/store/apps/details?id=app.tcan.lite)
